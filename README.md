# Sistema de Login y Registro

Proyecto básico de autenticación de usuarios con validación de formularios y manejo de datos.

## Tecnologías utilizadas
- Python
- MySQL
- HTML
- CSS

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Validación de datos
- Manejo de sesiones
- Conexión a base de datos

En desarrollo / versión académica.
